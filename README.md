# Sistema de Cardápio — Centro Educa Mais Dom Ungarelli

## Como abrir no VS Code

1. Extraia o arquivo ZIP.
2. Abra a pasta `sistema_cardapio_dom_ungarelli` no VS Code.
3. Abra o arquivo `index.html`.
4. Se tiver a extensão **Live Server**, clique com o botão direito em `index.html` e escolha **Open with Live Server**.
5. O sistema abrirá no navegador.

## Recursos

- Cardápio do café da manhã às 09:10h.
- Cardápio do almoço às 12:00h.
- Refeição da tarde às 15:00h.
- Fotos do café da manhã, almoço e lanche da tarde já inseridas.
- Logo do Centro Educa Mais Dom Ungarelli inserida no cabeçalho.
- Registro de presença por refeição.
- Resumo da presença abaixo dos cardápios.
- Área de sugestões dos estudantes abaixo do resumo da presença.
- Sugestões e presenças ficam salvas no `localStorage` do navegador.
- Layout responsivo para computador, tablet e celular.

## Observação

Este projeto é uma versão front-end. Os registros ficam salvos somente no navegador/computador utilizado. Para vários computadores compartilharem os mesmos dados, será necessário conectar o sistema a um banco de dados e uma API/backend.
